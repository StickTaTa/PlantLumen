# Reproduction notes

This repository contains two layers of material.

## Current manuscript summaries

`artefacts/summary/` holds the cohort-level summary tables reported in the current
manuscript. These are derived tables and do not require raw data or image features to read.

| Cohort | File |
|---|---|
| Barley | `artefacts/summary/barley_summary.json` |
| Maize | `artefacts/summary/maize_summary.json` |
| Arabidopsis | `artefacts/summary/arabidopsis_summary.json` |
| Norway spruce | `artefacts/summary/spruce_bench_summary.tsv` |
| Image R² | `artefacts/summary/image_r2_cohort_summary.txt` |

## Legacy stage-application demonstration

The packaged `plantlumen verify` and `scripts/report_s53.py` commands reproduce the
stage-application demonstration from the shipped 300-gene artefacts in `artefacts/`.
These files are retained so the scoring half of the chain can be checked without downloading
images or raw expression matrices.

```bash
python -m plantlumen verify
python scripts/report_s53.py
```

The U1 four-cohort pipeline used for the current manuscript is being consolidated into the
package. Until that consolidation is complete, the per-fold U1 tables are not regenerated by
this repository; the summary tables above are the values quoted in the manuscript.

## Data and feature caches

Raw GEO data, image feature caches and competitor implementations are not redistributed.
They remain available from the original repositories and the authors' official code.
